# HIGH TECH PS - Host Web Interface

موقع واجهة مستخدم متجاوب ومصمم بلغات HTML5, CSS3, و JavaScript مخصص لتقديم منصة تفاعلية تدعم العمل الأوفلاين عبر الـ Cache و Service Workers.

---

## 📁 هيكل المشروع (Project Structure)

```text
├── index.html        # الصفحة الرئيسية للواجهة
├── style.css         # ملف التنسيقات والأنيميشن (Dark Neon Theme)
├── cache.js          # شريط التقدم وإدارة ذاكرة التخزين المؤقت
├── sw.js             # Service Worker لتخزين الموارد للعمل أوفلاين
├── manifest.json     # ملف تهيئة تطبيق الويب (PWA)
├── cache.manifest    # ملف التخزين المؤقت التقليدي (AppCache)
└── README.md         # دليل الاستخدام والتوثيق
